# Swarm Game

Un juego sencillo de tower defense desarrollado con **Phaser 3** y **Vite**, que integra **MediaPipe** para el control mediante gestos manuales.

### Ejecucion con Docker
Para compilar y ejecutar el contenedor automáticamente, primero clonar el repositorio y luego ejecutar:

```bash
docker-compose up --build
```
Juego disponible en: [http://localhost:8080](http://localhost:8080)

##  Tecnologías Usadas
- **Phaser 3**: Motor de juego para la lógica y renderizado 2D.
- **MediaPipe**: Seguimiento de manos y reconocimiento de gestos.
